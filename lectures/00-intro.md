# Lecture 00 — What is Claude Code & Why It Matters

## What is Claude Code?

Claude Code is an **official command-line tool by Anthropic** that brings the power of Claude AI directly into your terminal. Unlike a chat interface, Claude Code:

- **Reads and writes files** on your computer
- **Understands entire codebases** (or documents, scripts, folders)
- **Executes terminal commands** on your behalf
- **Answers questions** about anything in your environment

Think of it as having a brilliant assistant sitting at your keyboard who can help with **any computer task** — from writing code, to organizing files, to drafting documents, to setting up software.

---

## Why Should You Care?

Even if you are not a programmer, Claude Code is useful for:

| Use Case | Example |
|----------|---------|
| Writing & editing | "Edit this email to be more professional" |
| File organization | "Rename all these files by date" |
| Research | "Summarize this PDF for me" |
| Learning technology | "Explain what this error means" |
| Business tasks | "Build me a simple spreadsheet formula" |

---

## How Does It Differ from ChatGPT or Claude.ai?

| Feature | Claude.ai (browser) | Claude Code (terminal) |
|---------|--------------------|-----------------------|
| Access to your files | ❌ No | ✅ Yes |
| Run commands | ❌ No | ✅ Yes |
| Understand whole project | ❌ Limited | ✅ Full |
| Technical skills needed | None | Minimal (we'll teach you!) |

---

## The Big Picture

```
You (in words)  →  Claude Code  →  Your Computer
 "Make this file"   (understands)    (creates the file)
```

You describe what you want in plain language. Claude Code figures out how to do it and does it.

---

## Key Concepts

- **Anthropic** — the AI safety company that created Claude (founded by ex-OpenAI researchers)
- **Claude** — the AI model (like GPT-4 but by Anthropic)
- **Claude Code** — the terminal tool that connects Claude to your machine
- **API Key** — your personal password that authorizes Claude Code to use Claude's intelligence
